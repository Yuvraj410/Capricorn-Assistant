# Capri voice samples to record (fish.audio, Capri voice)

Paste the contents of each `*.tagged.txt` into fish.audio, generate, download the mp3 and
save it **in this folder** with the same base name:

| Paste this            | Save the mp3 as     | What it's for |
|-----------------------|---------------------|---------------|
| lines-3.tagged.txt    | lines-3.mp3         | web + music replies |
| lines-4.tagged.txt    | lines-4.mp3         | playback + minimal mode |
| lines-5.tagged.txt    | lines-5.mp3         | her volume, chat, errors |
| lines-6.tagged.txt    | lines-6.mp3         | power + "Go ahead, choom" prompts |
| capri-happy.tagged.txt     | capri-happy.mp3     | mood voice: friendly / done |
| capri-playful.tagged.txt   | capri-playful.mp3   | mood voice: jokes, laughing |
| capri-sad.tagged.txt       | capri-sad.mp3       | mood voice: sorry / couldn't do it |
| capri-surprised.tagged.txt | capri-surprised.mp3 | mood voice: whoa / excited |
| capri-angry.tagged.txt     | capri-angry.mp3     | mood voice: nope / warnings |
| capri-calm.tagged.txt      | capri-calm.mp3      | mood voice: plain info |

Keep the plain `.txt` files: they're the transcripts used to cut the packs into single lines.

**lines-N** = exact lines Capri says. Each is cut out and played as the real recording.
**capri-<mood>** = one ~12-15 s clip per mood. Her cloned voice copies the delivery of the clip,
so every reply (including AI replies that were never recorded) is said in the matching mood.

Tips: one take per file, no music, a short pause between lines (fish.audio does this by itself).
If a take sounds off, regenerate just that file.

Pronunciation: the paste-in scripts spell "preem" as **"Pream"** (rhymes with dream) so fish.audio
says it right; the plain .txt transcripts keep the real spelling. Do the same for any line you add.
